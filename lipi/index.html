Lipi

A free keyboard for writing correct Unicode Nepali in any app, in the layout you already know.

Download Lipi 0.1.6

  • Windows installer ↗84 MB, hosted on Google Drive
  • macOS (.dmg)macOS disk image · 0.8 MB
  • Chrome extension (.zip)Load unpacked in Chrome · 0.3 MB

Two layouts

Romanized: type Nepali the way it sounds on an English keyboard (k → क, a → ा). Traditional: the classic Nepali typewriter layout used in offices. Switch at any time.

Install

Windows

  1. Download the installer and run it.
  2. If Windows SmartScreen appears, choose More info, then Run anyway.
  3. Switch to Lipi with Windows + Space, then pick Romanized or Traditional.

macOS

  1. Open the .dmg and double-click Install Lipi. It installs the keyboard and turns it on.
  2. If macOS says the app is from an unidentified developer, right-click it and choose Open.
  3. Choose Lipi from the input menu in the menu bar.

Chrome

  1. Unzip the file.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and choose the folder that contains manifest.json.
  4. Pin Lipi. Use the popup or side panel to switch layouts.
