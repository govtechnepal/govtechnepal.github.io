गृहपृष्ठ / परियोजना

Type Nepali

लिपि

हजुरलाई पहिल्यै परिचित लेआउटमा, जुनसुकै एपमा शुद्ध युनिकोड नेपाली लेख्ने निःशुल्क किबोर्ड।

लिपि ०.१.६ डाउनलोड

  • विन्डोज इन्स्टलर ↗८४ MB, गुगल ड्राइभमा
  • म्याकओएस (.dmg)म्याकओएस डिस्क इमेज · 0.8 MB
  • क्रोम एक्सटेन्सन (.zip)क्रोममा Load unpacked गर्नुहोस् · 0.3 MB

दुई लेआउट

रोमनाइज्ड: अङ्ग्रेजी किबोर्डमा उच्चारणअनुसार नेपाली टाइप गर्नुहोस् (k → क, a → ा)। परम्परागत: कार्यालयमा प्रयोग हुने पुरानो नेपाली टाइपराइटर लेआउट। जुनसुकै बेला फेर्न सकिन्छ।

इन्स्टल गर्ने तरिका

Windows

  1. इन्स्टलर डाउनलोड गरेर चलाउनुहोस्।
  2. विन्डोज स्मार्टस्क्रिन देखियो भने More info, अनि Run anyway छान्नुहोस्।
  3. Windows + Space थिचेर लिपिमा जानुहोस्, अनि रोमनाइज्ड वा परम्परागत छान्नुहोस्।

macOS

  1. .dmg खोलेर Install Lipi मा डबल-क्लिक गर्नुहोस्। यसले किबोर्ड इन्स्टल गरेर सक्रिय गर्छ।
  2. एप अज्ञात डेभलपरको हो भनेर म्याकओएसले देखायो भने राइट-क्लिक गरेर Open छान्नुहोस्।
  3. मेनु बारको इनपुट मेनुबाट लिपि छान्नुहोस्।

Chrome

  1. फाइल अनजिप गर्नुहोस्।
  2. chrome://extensions खोलेर Developer mode सक्रिय गर्नुहोस्।
  3. Load unpacked थिचेर manifest.json भएको फोल्डर छान्नुहोस्।
  4. लिपिलाई पिन गर्नुहोस्। लेआउट फेर्न पपअप वा साइड प्यानल प्रयोग गर्नुहोस्।
