Contribute

Everything here is open source, and there is a place for you whether you write code or not.

GitHub

Issues, plans and code live on GitHub. Start by reading open issues or opening a new one.

Open on GitHub ↗

How to help

  • Write codeFix bugs, package software for Debian, improve the keyboards.
  • Translate and reviewMake interfaces and guides read naturally in Nepali.
  • TestTry NepalOS and Lipi on the hardware and apps offices actually use, and report what breaks.
  • Design and accessibilityHelp make every screen clear and usable for all, including the Mountain fonts.
  • Write documentationGuides for installers, IT staff and everyday users.
  • Share what offices needPublic servants: tell us where software gets in the way.

Getting started

  1. Pick a project: NepalOS, Lipi, the Rasuwa Flood Bulletin or the Mountain fonts.
  2. Open an issue describing what you want to do, or comment on an existing one.
  3. Send a pull request. Small, focused changes are easiest to review.

Licences

  • Fonts: SIL Open Font License 1.1 (OFL). This site uses Mukta (OFL); the Mountain fonts will be released under the OFL.

Propose a project

Good proposals solve a real problem for a public office, can be open source, and build on existing tools where possible. Open a GitHub issue that describes the problem first, then the idea.

Please don’t share personal or confidential government data in any public issue or discussion.
